## 2. Project Title

DANK — Reputation-Based Credit on Monad

## 3. Category

DeFi / Lending

## 4. Description

DANK is a reputation-based, unsecured lending prototype on Monad. Borrowers access credit through reputation and guarantor support instead of locking collateral. Smart contracts enforce a minimum score of 80 and a total guarantee capacity that cannot be multiplied across loans.

Liquidity providers sign an onchain risk acknowledgment before depositing and receive proportional pool shares. Collected repayments flow back to the pool. A public dashboard shows loans, outstanding principal, repayment schedules, guarantors, liquidity providers and transaction proofs without requiring a wallet connection.

Our Monad testnet demo uses six explicitly labeled synthetic profiles: five wallets received loans, one was rejected onchain, and two loans were fully repaid. A separate 10,000 test USD deposit received one-sixth of an initially 50,000 test USD pool.

The app and documentation support Turkish, English, German, Spanish and French. Historical DeFi data integration is planned; current test scores are administrator-assigned. USD is a test token with no real monetary value.
